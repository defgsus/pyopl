# Python AdLib/OPL3 library

Wrapper around [Nuked OPL3](https://github.com/nukeykt/Nuked-OPL3).





## Development

```shell
python -m venv env
source env/bin/activate

pip install -U build
python -m build

pip install --force-reinstall dist/*.whl

python -m unittest discover tests/
```
